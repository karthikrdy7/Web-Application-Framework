View

The View is the component of the MVC architecture that is responsible for the user interface (UI) and presentation of data.
It displays the information received from the Model to the user in a clear and understandable format.
The View does not contain business logic or directly interact with the database; it only presents data and collects user input.

Responsibilities of the View

Displays data to the user.
Provides the graphical user interface (GUI) or web pages.
Receives user input such as button clicks, form submissions, or menu selections.
Sends user actions to the Controller for processing.
Updates the displayed information whenever the Model changes.

Examples of User Interface Elements

User Interface (UI) elements are the visual components that allow users to interact with an application.

Common Examples


Button – Used to perform an action (e.g., Login, Submit, Save).
Text Box (Text Field) – Allows users to enter text such as a username or email.
Password Field – Used to securely enter passwords by masking the characters.
Radio Button – Allows users to select only one option from a group (e.g., Gender: Male/Female).
Menu Bar – Provides navigation options such as File, Edit, View, and Help.
Navigation Bar – Helps users move between different pages or sections of an application.
Image/Icon – Represents actions or information visually (e.g., search icon, home icon).
